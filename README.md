# Job Workspace

Локальное веб-приложение для ведения работы от плана до принятого результата. У задачи есть планировщик, исполнитель, ревьюер и владелец. План, решения, обсуждение и материалы хранятся в одной задаче.

## Запуск

Понадобится Python 3.11 или новее. Команду нужно выполнить из корня проекта.

```sh
python3 -m job_workspace --demo
```

Откройте [Job Workspace](http://127.0.0.1:8765). `--demo` заполняет пустую базу тремя вымышленными задачами. Для чистого рабочего пространства запустите команду без `--demo` с новой базой.

```sh
python3 -m job_workspace --db .data/my-workspace.sqlite3 --port 8765
```

По умолчанию база находится в `.data/workspace.sqlite3`. После перезапуска приложение открывает ту же базу и сохраняет текущий этап каждой задачи.

## Что попробовать

1. Откройте демозадачу **Обновить онбординг команды** и рассмотрите запрос на публикацию памятки.
2. Запишите решение и нажмите **Продолжить работу**. Оно останется в журнале вместе с исходным запросом.
3. Передайте результат на ревью с одним или несколькими материалами. Материалом может быть ссылка, путь или название документа.
4. Верните результат на доработку с замечанием. Передайте новую версию и затем примите её.
5. Создайте свою задачу, отправьте план на согласование и попробуйте заменить его новой версией до одобрения.

## Как устроено

- План задаёт ресурсы и критерии приёмки. Каждая версия имеет SHA-256 идентификатор. Решение относится к точной версии.
- Публикация, изменение доступа, удаление и другие внешние действия требуют отдельного решения по выбранному ресурсу из плана. Пауза и решение переживают перезапуск. Действия выполняют люди и фиксируют их ход в приложении.
- Каждая отправка на ревью хранит версию результата и материалы. Завершение требует приёмки актуальной версии.
- SQLite сохраняет состояние, событие и идентификатор команды одной транзакцией. Повтор того же запроса не создаёт второго события. Команда из устаревшей вкладки получает конфликт версии.

Интерфейс написан на HTML, CSS и JavaScript. Сервер использует стандартную библиотеку Python и слушает `127.0.0.1`. Приложение рассчитано на личное локальное использование. Имена ролей сохраняются для истории работы.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют ревизии планов, границы ресурсов, паузу после перезапуска, цикл ревью, повтор запроса и конфликт при одновременном обновлении.
